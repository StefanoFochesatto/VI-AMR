# VI-AMR

This repository started as support for S. Fochesatto (2024). _Adaptive mesh refinement for variational inequalities_, Master of Science project, UAF, and a paper in progress.

It still has materials related to the paper, and for presentations on the topic, and etc.

The actual algorithms are now in a separate, maintained Python library at [github.com/StefanoFochesatto/viamr](https://github.com/StefanoFochesatto/viamr).  Users should go there for all up-to-date code and examples.
